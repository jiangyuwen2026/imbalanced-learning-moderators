# Imbalanced Learning Moderators

Data Characteristics as Critical Moderators of Oversampling Method Selection

## Project Overview

This repository contains the implementation for the paper:
**"Beyond Imbalance Ratio: Data Characteristics as Critical Moderators of Oversampling Method Selection"**
(Target: Pattern Recognition)

## Repository Structure

```
├── src/                    # Core implementation
├── data/                   # Dataset generation and loading
├── experiments/            # Experimental scripts
├── results/                # Analysis results
├── figures/                # Generated figures
└── docs/                   # Documentation
```

## Installation

```bash
git clone https://github.com/jiangyuwen2026/imbalanced-learning-moderators.git
cd imbalanced-learning-moderators
pip install -r requirements.txt
```
