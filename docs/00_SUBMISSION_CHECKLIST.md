- 注册账号（如没有）
- 或使用现有账号登录

### Step 2: 开始新投稿
```
1. Click "Submit New Manuscript"
2. Select Article Type: "Research Paper"
3. Enter Title: "Beyond Imbalance Ratio: Data Characteristics as Critical Moderators of Oversampling Method Selection"
4. Paste Abstract (from Manuscript_PR.tex)
5. Keywords: class imbalance, oversampling method selection, imbalance ratio, data characteristics, class separability
```
